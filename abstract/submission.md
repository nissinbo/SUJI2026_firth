# 演題登録情報

演者: 〇西川寛来（協和キリン）、後藤駿輔（ノバルティス ファーマ）

タイトル: SASとRにおけるFirth法の実装差の整理と数値的評価

要旨（100字以内）

Firth 法によるロジスティック回帰の実装は SAS と R で異なることが CAMIS で報告されている。本研究では、結果に差が生じる仕組みを整理し、差が大きくなる条件を数値的に評価する。

概略（500字以内）

ロジスティック回帰では、完全分離および準完全分離の状況では最尤推定量が存在しない。Firth 法はこの問題の対処法として知られており、分離が生じた場合でも推定値を得ることができる。
Firth 法の実装として SAS では PROC LOGISTIC、R では logistf や brglm2 などがあるが、既定の推論方法や収束判定の基準が異なるため、同一データでも出力が一致しないことがある。この点は SAS と R の実装差を整理するワーキンググループ CAMIS でも報告されている。ただし、SAS と R の各実装では複数の差異があるため、既定の方法を用いた場合に生じる差の全体像は整理されていない。本研究ではまず、点推定・信頼区間・検定等について実装間での一致・不一致を整理し、出力をできる限り揃えるための設定をまとめる。次に、標本サイズ、イベント発生割合、分離の有無等によって出力の差の大きさがどう変わるかを数値的に評価する。
